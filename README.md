# 美股投资跟踪台

把零散的美股信息整理成可执行的决策线索，并把世界局势通过 3D 地球可视化。

## 一、怎么看

两种方式，任选其一：

```bash
# 方式 1：直接双击 index.html（数据文件用 <script src> 引入，file:// 下也能读）
open index.html

# 方式 2：起本地服务（推荐，行为与线上一致）
python3 -m http.server 8899
# 然后打开 http://localhost:8899
```

## 二、怎么刷新数据

```bash
python3 refresh.py            # 抓取行情 → 写入 data/market.js
python3 refresh.py --dry      # 只打印不写文件
```

依赖已装在隔离环境，用这个解释器：
`/Users/xhx-s/.workbuddy/binaries/python/envs/default/bin/python refresh.py`

**定时任务**（美股收盘 ≈ 北京时间 04:00，盘前 ≈ 20:30）：

```cron
30 4  * * 1-6  cd /path/to/us-market-tracker && /path/to/python refresh.py
30 20 * * 1-6  cd /path/to/us-market-tracker && /path/to/python refresh.py
```

`refresh.py` 只更新**数值型**数据（指数、个股、波动率、商品、美元指数）。
「三件大事」「后续关注清单」「世界局势事件」需要判断与写作，由 AI 在定时任务中更新
（对应文件：`assets/app.js` 里的 `TODAY_TOP3` / `WATCH_LIST`，以及 `data/events.js`）。

## 三、目录结构

```

assets/
  style.css           样式
  app.js              主逻辑 + 决策引擎（TODAY_TOP3 / WATCH_LIST 在这里）
  globe.js            3D 地球（Three.js，无 WebGL 时降级 2D）
  vendor/three.min.js 本地 three.js r160（离线可用）
data/
  market.js           实时行情（refresh.py 生成，勿手改）
  macro.js            宏观指标（人工核校，逐条标来源）
  events.js           世界局势事件（人工核校，逐条标来源）
  geo.js              简化世界地图轮廓（build_geo.py 生成）
  countries-110m.json 原始 TopoJSON（world-atlas，仅生成时用）
```

## 四、数据源与口径

| 数据 | 来源 | 说明 |
|---|---|---|
| 美股指数 / 个股 / 商品快照 | 腾讯财经 `qt.gtimg.cn` | 免费无需 key |
| VIX 恐慌指数 | 新浪财经 `znb_VIX` | 腾讯的 `usVIX` 长期不更新，已弃用 |
| 美元指数 | 新浪 `DINIW` | 东财 `100.UDI` 作备胎 |
| 日K（美股 / 美股指数） | 新浪美股 `US_MinKService` | 东财 `push2his` 偶发断连，作备胎 |
| 日K（A股指数） | 腾讯 `fqkline` | — |
| 宏观指标 | FRED / BLS / BEA / CME，经 Schwab、Saxo、第一财经等转引 | 每条标来源与时间 |
| 事件与新闻 | 新华社、央视、路透、Schwab、Saxo、第一财经 | 每条标来源与时间 |

### 关于「纳指恐慌指数」和「中证红利恐慌指数」

VXN（CBOE 纳指100 波动率指数）和中证红利对应的隐含波动率指数**没有免费实时源**——
CBOE 官方 CSV 被 Cloudflare 拦截、Yahoo 与 Stooq 均已失效、新浪无对应代码。

所以本页统一改用**已实现波动率**口径，两者可以直接横向比较：

```
HV20 = 近 20 个交易日日收益标准差 × √252 × 100
HV60 = 近 60 个交易日
分位 = 当前 HV20 在过去 250 个交易日 HV20 序列中的百分位
```

- 纳指用 **NDX**（纳斯达克100，与 VXN 的标的一致）
- 中证红利用 **000922.SH**

口径可复现，计算代码在 `refresh.py` 的 `realized_vol()` / `hv_percentile()`。

## 五、决策引擎的规则（透明、可核对）

基准仓位 50%，每个信号 ±6 个百分点，上限 85%、下限 20%：

| 信号 | 条件 | 分值 |
|---|---|---|
| VIX | <15 / 15–20 / 20–25 / >25 | +2 / 0 / −1 / −2 |
| 纳指波动分位 | <30% / 30–70% / >70% | +1 / 0 / −1 |
| 纳指距 52 周高点 | <2% / 2–5% / >5% | +1 / 0 / −1 |
| 10 年期美债 | ≥5% / <4.5% | −1 / +1 |
| 10 月加息概率 | ≥60% | −1 |
| 布伦特原油 | ≥100 美元 | −1 |

再按风险偏好调整：保守 −10、平衡 0、进取 +8。
规则写在 `assets/app.js` 的 `scoreMarket()`，改阈值直接改那里。

止损默认为成本的 −12%，止盈 +25%；浮盈超 15% 后止损线上移至成本价（保本）。

## 六、改自选池

默认池在 `refresh.py` 的 `DEFAULT_WATCH`（网页上也能临时增删，存在浏览器 localStorage）。
要让它有实时数据，必须同时加进 `DEFAULT_WATCH` 并重跑脚本——网页上的增删只影响你本机显示。

## 六点五、v3 改造（产品级工具化）

按产品规范把「研究报告式长文」改成「盘前 5 分钟检查台」：

- **双主题**：暗色为默认（金融工具标配），浅色 = 性冷淡 + 马卡龙。右上角一键切换，记住选择。
- **今日快照**：首屏 6 张指标卡（大盘状态 / 纳指 / VIX / 10Y / DXY / 下次事件），
  每卡带状态色点 + 时效戳 + 休市倒计时，点击展开说明。
- **数据时效状态机**：LIVE / DELAYED / CLOSED / STALE / MANUAL 五态，
  宁可显示「已过时」，也不静默展示过期数字。
- **验证点追踪表**：三件大事 + 世界局势的全部可证伪验证点集中成表，
  三态勾选（未验证 / 已验证 / 被证伪），存 localStorage。这是最值得长期积累的资产。
- **图表化**：52 周区间条（带当前位置圆点）、VIX 0–30 刻度条、
  影响链条改为横向流程图、全球风险温度计。
- **模块折叠** + 滚动迷你状态栏 + 导航横向滚动提示（8 项全可达）。
- **内容层**：每个模块末尾加「所以呢」，宏观与决策中心加「我不知道」，
  交易逻辑与宏观加「反着看」。

刻意偏离规范的两点：
1. **保留红涨绿跌**（中国用户习惯），未按西式配色（绿涨红跌）。
2. 浅色主题沿用马卡龙色板，未按「10 色」的严格约束。

## 七、线上访问

已发布：<https://us-market-tracker.app.workbuddy.host/>

手机、平板、别人的电脑都能直接打开，无需安装。

⚠️ **部署的是快照**。线上数据不会自己更新——每次改完内容或跑完 `refresh.py` 后，
需要重新发布一次（在 WorkBuddy 里说「重新发布」即可）。

想让线上自动更新，有两条路：
1. 把项目托管到 GitHub Pages / Cloudflare Pages，用 GitHub Actions 定时跑 `refresh.py` 并提交——真正的每日自动更新。
2. 保持现在的静态部署，只在需要时手动重新发布。

## 八、设计上刻意坚持的几条

- **每个事件都要有「可证伪的验证点」**：不说"注意风险"，而是说"10 年期收回 5% 下方 = 警报解除"。
  没有验证点的判断，事后永远无法复盘对错。
- **「已定价程度」+「非对称性」**：不只说会发生什么，还要说利好还剩多少没被价格反映、
  以及好消息和坏消息哪个杀伤更大。
- **指标要交叉解读，不能各说各话**：VIX 低但已实现波动率高 = 背离，比单看任何一个都有信息量。
- **术语现场解释**：久期、鹰鸽、基点在正文里就地解释，不假设读者懂。
- **结论先行**：个股点评第一段就是结论，后面才是论证。
